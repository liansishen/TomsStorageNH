## Changes

- Updated the Modernity adapter's cover to use the same frame, colors and pixel style as the BackpackEnhance adapter, with a central **T**.
- Added versioned, reproducible Modernity resource-pack packaging to the Gradle build.
- Standardized releases: open a PR, wait for CI, merge, wait for master-branch CI, then publish through a version tag.
- Added automatic upload of the Modernity adapter ZIP to the same release as the mod JARs.

## Downloads

Use `tomsstorage-0.2.2.jar` for the mod. For Modernity-style storage and crafting terminal GUIs, also download `Modernity-TomsStorage-0.2.2.zip`, place it in Minecraft's `resourcepacks` directory and enable it above Modernity.

The development and sources JARs are also included.

**Full Changelog**: https://github.com/liansishen/TomsStorageNH/compare/0.2.1...0.2.2
